<h1 align="center">VK Ads MCP All in One</h1>

<p align="center">Локальный MCP-сервер для работы с официальным VK Ads API.</p>

Сервер подключает MCP-клиент к VK Рекламе: читает кампании, группы и объявления, получает статистику, работает с аудиториями, креативами, лид-формами, опросами, подписками, прайс-листами и справочниками. Отдельный блок Core VK API ищет и анализирует публичные сообщества.

В текущей версии зарегистрировано 128 инструментов. Полный успешный live-тест прошли 102 инструмента; ещё 26 честно отмечены как непроверенные или неработающие. Все 10 инструментов сообществ пока имеют статус `⛔️`: их live-проверка намеренно отложена.

> [!IMPORTANT]
> Сервер регистрирует инструменты чтения и записи одновременно. Вызов write tool сразу выполняет операцию после встроенного preflight. Не вызывайте создание, изменение, удаление, загрузку, отправку или экспорт без явного намерения пользователя.

## Быстрый старт

Нужны:

- Node.js 22 или новее;
- `client_id` и `client_secret` приложения VK Ads;
- авторизованный GitHub CLI, пока репозиторий остаётся приватным.

### macOS и Linux — приватный репозиторий

```bash
gh auth login
gh api -H "Accept: application/vnd.github.raw+json" repos/sergeylopukhov/vk-ads-mcp-all-in-one/contents/install.sh | sh
```

### Windows — приватный репозиторий

Откройте PowerShell:

```powershell
gh auth login
gh api -H "Accept: application/vnd.github.raw+json" repos/sergeylopukhov/vk-ads-mcp-all-in-one/contents/install.ps1 | Out-String | Invoke-Expression
```

Установщик:

1. скачает последнюю версию;
2. установит зависимости и соберёт сервер;
3. запросит `client_id`;
4. запросит `client_secret` со скрытым вводом;
5. предложит подключить поиск сообществ через отдельный OAuth VK;
6. сохранит credentials и токены в локальном `auth.env`;
7. подключит сервер к Codex под именем `vk-ads`;
8. установит навык Codex для безопасной работы с текущими tools.

Навык включается автоматически для задач о VK Ads и сообществах VK. Он
маршрутизирует запросы по точным MCP tools, помогает восстанавливать токены,
проводить диагностику, анализировать статистику и сообщества, управлять
кампаниями, аудиториями, лидами и опросами, а также безопасно выполнять очистку.
Для анализа по умолчанию используется подробный отчёт; записывающие tools
вызываются только по явному запросу пользователя. Навык и его справочники
обновляются вместе с сервером.

После установки перезапустите Codex и отправьте:

```text
Проверь подключение к VK Рекламе и покажи доступные кампании. Ничего не меняй.
```

## Обновление

Повторно выполните команду установки. Установщик покажет установленную и доступную версии:

- «обновить» заменит сервер и навык Codex, но сохранит `auth.env`, токены и локальный аудит;
- «установить заново» повторно запросит `client_id` и `client_secret`, а сохранённые токены очистит.

Каталог установки по умолчанию:

- macOS: `~/Library/Application Support/VK Ads MCP`;
- Linux: `~/.local/share/vk-ads-mcp`;
- Windows: `%LOCALAPPDATA%\VK Ads MCP`.

Для другой папки или ветки:

```bash
node install.mjs --install-dir "/полный/путь" --ref main
```

Все параметры:

```bash
node install.mjs --help
```

## Как создаётся и хранится токен

Учётные данные хранятся только в `auth.env` внутри каталога установки:

```dotenv
VK_ADS_CLIENT_ID=
VK_ADS_CLIENT_SECRET=
VK_ADS_TOKEN=
VK_ADS_REFRESH_TOKEN=
VK_ADS_TOKEN_EXPIRES_AT=
VK_API_TOKEN=
VK_API_TOKEN_TYPE=vk_id
VK_API_CLIENT_ID=
VK_API_DEVICE_ID=
VK_API_REFRESH_TOKEN=
VK_API_TOKEN_EXPIRES_AT=
VK_COMMUNITY_RESEARCH_TTL_DAYS=30
```

При первом запросе сервер получает токен по `client_id` и `client_secret`. Если VK Ads возвращает `refresh_token`, сервер сохраняет его и обновляет access token заранее.

Истекающий token обновляется автоматически. После HTTP `401` сервер один раз обновляет отклонённую пару и повторяет запрос. Для ручного обновления используется `vk_ads_oauth_token_refresh`. Если пара была полностью отозвана на другом компьютере и refresh невозможен, `vk_ads_oauth_current_tokens_delete` удаляет все токены настроенного аккаунта без предварительной проверки старого access token, очищает локальные значения и запрашивает новую пару.

Инструменты сообществ используют только отдельный `VK_API_TOKEN`. По умолчанию установщик предлагает совместимый legacy OAuth через встроенное приложение VK с `client_id=6270012`; достаточно нажать Enter. При выборе VK ID нужно указать своё приложение, а также можно сохранить `VK_API_CLIENT_ID`, `VK_API_DEVICE_ID`, `VK_API_REFRESH_TOKEN` и срок действия — сервер обновит Core VK token при старте.

`auth.env` исключён из Git и npm-пакета. На macOS и Linux установщик создаёт его с правами `0600`. Токены, `client_secret` и полные приватные ответы VK Ads не выводятся через MCP.

## Безопасность записи

Записывающие инструменты используют фиксированные API-маршруты и строгие входные схемы. Для операций над существующим объектом сервер сначала читает актуальное состояние. После изменения он повторно читает объект или коллекцию, когда VK Ads предоставляет подходящий контракт.

Успешный HTTP-ответ не считается доказательством изменения. Если контрольное чтение не подтвердило результат, MCP возвращает ошибку или неподтверждённый итог. Например, `remoderated=false` не превращается в успешную перемодерацию.

Санитизированный журнал записи хранится локально в `.vk-ads-audit.jsonl`. В нём нет токенов, payload, ID кампаний, названий или ответов провайдера.
