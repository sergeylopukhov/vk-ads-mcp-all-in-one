# Участие в разработке

1. Не добавляйте токены, `client_secret`, персональные данные, приватные ответы VK Ads, `auth.env` и локальный аудит.
2. Проверяйте каждый API-маршрут, HTTP-метод и схему по актуальной официальной документации VK Ads.
3. Для нового tool добавляйте строгие входные и выходные схемы, обработку ошибок и сфокусированные тесты.
4. Для записи сохраняйте preflight, одноразовый запрос, санитизированный аудит и контрольное чтение, когда оно поддерживается.
5. Не ставьте `✅` в [tools.md](tools.md), пока точный MCP tool не прошёл успешный live-тест в выделенном тестовом кабинете.

Перед commit запустите:

```bash
npm ci
npm run typecheck
npm test
npm run build
npm pack --dry-run
```

Публичный контракт и live-статусы должны оставаться синхронизированы с реальным сервером.
