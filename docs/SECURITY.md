# Безопасность

## Поддерживаемая версия

Исправления безопасности вносятся в актуальную ветку и последний релиз.

## Сообщить об уязвимости

Не публикуйте токены, `client_secret`, персональные данные, рекламные данные или детали уязвимости в GitHub Issues. Отправьте краткое описание и безопасный способ связи на `sergey.lopukhov@gmail.com`.

Если секрет уже раскрыт, сначала отзовите его в VK Ads, затем сообщите об инциденте.

## Локальные секреты

Сервер хранит учётные данные и токены только в `auth.env` внутри каталога установки. Файл:

- исключён из Git и npm-пакета;
- создаётся с правами `0600` на macOS и Linux;
- не может быть символической ссылкой;
- обновляется через атомарную замену;
- не передаётся MCP-клиенту.

Не добавляйте реальные данные в репозиторий, GitHub Issues, логи, скриншоты или историю команд.

## Операции записи

Инструменты чтения и записи доступны одновременно. После вашего запроса на изменение MCP-клиент передаёт точные входные данные в `vk_ads_action_prepare` и проверяет ответ `ready`. Инструмент подготовки использует актуальные данные провайдера, но не выполняет POST, DELETE или загрузку файла. Запись начинается только при `ready: true` и после вашего подтверждения.

Все 64 инструмента записи повторяют общий preflight непосредственно перед изменением. Для существующих объектов сервер использует свежие данные провайдера и контрольное чтение результата, когда такой контракт доступен. Неоднозначный, частичный или неподтверждённый результат не считается успехом.

Локальный `.vk-ads-audit.jsonl` содержит только время, операцию и исход. В нём нет учётных данных, содержимого запросов, идентификаторов рекламных объектов, названий и ответов VK Ads.
