# Безопасность

## Поддерживаемая версия

Исправления безопасности вносятся в актуальную ветку и последний релиз.

## Сообщить об уязвимости

Не публикуйте токены, `client_secret`, персональные данные, рекламные данные или детали уязвимости в issue. Отправьте краткое описание и безопасный способ связи на `sergey.lopukhov@gmail.com`.

Если секрет уже раскрыт, сначала отзовите его в VK Ads, затем сообщите об инциденте.

## Локальные секреты

Сервер хранит учётные данные и токены только в `auth.env` внутри каталога установки. Файл:

- исключён из Git и npm-пакета;
- создаётся с правами `0600` на macOS и Linux;
- не может быть символической ссылкой;
- обновляется через атомарную замену;
- не передаётся MCP-клиенту.

Не добавляйте реальные данные в `.env.example`, тесты, issue, логи, скриншоты или историю команд.

## Операции записи

Текущий сервер регистрирует read и write tools одновременно. Вызов write tool сразу выполняет операцию после встроенного preflight. MCP-клиент или агент обязан получить намерение пользователя до вызова.

Для существующих объектов сервер использует свежие данные провайдера и контрольное чтение результата, когда такой контракт доступен. Неоднозначный, частичный или неподтверждённый результат не считается успехом.

Локальный `.vk-ads-audit.jsonl` содержит только время, операцию и исход. В нём нет credentials, payload, ID рекламных объектов, названий и ответов VK Ads.
