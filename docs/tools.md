<h1 align="center">Инструменты VK Ads MCP</h1>

<p align="center">Каталог возможностей текущего MCP-сервера для VK Рекламы.</p>

В каталоге перечислены все инструменты текущей версии сервера.

> [!IMPORTANT]
> Инструменты со статусом `⛔️` могут завершиться ошибкой или вернуть неподтверждённый результат. Не используйте их для изменений в рабочем кабинете.

## Как читать каталог

| Обозначение | Значение |
| --- | --- |
| `✅` | Инструмент проверен в VK Рекламе и доступен для обычной работы. |
| `⛔️` | Инструмент пока не проверен или не работает. |
| `read` | Читает данные или выполняет проверку без изменения рекламного кабинета. |
| `write` | Создаёт, изменяет, удаляет, загружает, отправляет или сохраняет данные. |

Сейчас в каталоге 128 инструментов: 102 доступны для обычной работы, 26 пока не проверены или не работают.

## Рекомендуемый порядок работы

1. Вызвать `vk_ads_connection_check` и проверить подключение к нужному рекламному кабинету.
2. Перед изменением прочитать нужный объект и проверить его идентификатор, текущий статус и родительские связи.
3. Выполнить одну согласованную операцию с помощью инструмента записи.
4. Проверить результат инструментом чтения, если VK Ads позволяет получить изменённый объект.
5. Не использовать инструменты со статусом `⛔️` для изменений в рабочем кабинете.

Универсального инструмента для произвольных запросов нет. У каждого инструмента свой контракт и разрешённый путь VK Ads.
