# Подключение к Codex

Нужны Node.js 22 или новее с npm, `client_id` и `client_secret` приложения VK Ads.

## Установка

```bash
npx --yes github:sergeylopukhov/vk-ads-mcp-all-in-one
```

Установщик запросит `client_id`, скроет ввод `client_secret`, соберёт сервер и покажет найденные MCP-клиенты с галочками. Оставьте Codex отмеченным, снимите пробелом ненужные галочки и нажмите Enter. Установщик зарегистрирует подключение `vk-ads` и добавит навык в `~/.agents/skills/vk-ads-mcp/`.

При первом обновлении старую копию из `~/.codex/skills/vk-ads-mcp/` установщик сохранит в `~/.codex/skill-backups/`, чтобы Codex не показывал два одинаковых навыка.

Чтобы выбрать Codex без интерактивного вопроса:

```bash
npx --yes github:sergeylopukhov/vk-ads-mcp-all-in-one --clients codex
```

Перезапустите Codex и отправьте:

```text
Проверь подключение к VK Рекламе и покажи доступные кампании. Ничего не меняй.
```

## Обновление

Повторите команду установки:

- обновление сохраняет `auth.env`, токены и локальный аудит;
- переустановка запрашивает учётные данные заново.

## Проверка подключения

Установщик выполняет:

```bash
codex mcp remove vk-ads
codex mcp add vk-ads -- node "/полный/путь/к/VK Ads MCP/dist/index.js"
```

Проверить регистрацию можно командой:

```bash
codex mcp get vk-ads
```

Первый безопасный инструмент — `vk_ads_connection_check`.

## Запись

При запросе на изменение Codex сначала передаёт имя действия и точные входные данные в `vk_ads_action_prepare`. Инструмент проверяет схему и актуальное состояние кабинета, затем возвращает `ActionReadiness` без записи.

При `ready: false` Codex сообщает, какие условия мешают выполнить действие. Связанный объект изменится только после вашего отдельного запроса. При `ready: true` вы увидите подготовленное действие и сможете подтвердить его. После подтверждения сервер выполнит одну операцию и повторно прочитает результат, если VK Ads поддерживает такую проверку.
