# Лицензия и атрибуция

## Этот проект

`vk-ads-mcp` распространяется по лицензии MIT. Полный текст находится в [LICENSE](../LICENSE).

Код, тесты, установщики и документация текущего сервера относятся к новой реализации.

Обложка `docs/img/cover.png`, логотип `docs/img/logo.png` и общий стиль публичной документации перенесены из предыдущего проекта автора `vk-ads-mcp-all-in-one-old`.

Старые инструменты, API-контракты и реализация сервера не переносились.
