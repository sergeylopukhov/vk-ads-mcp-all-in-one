# История изменений

## 0.0.2 — 2026-07-29

### Установка

- Для Windows, macOS и Linux используется одна команда `npx`.
- Единственный установочный файл — `install.mjs`. Отдельные загрузчики для shell и PowerShell больше не нужны.

## 0.0.1 — 2026-07-29

Первый ранний релиз. До отдельного решения новые версии увеличивают только
третью цифру: `0.0.2`, `0.0.3` и далее.

### Приложение для поиска сообществ

- Для поиска сообществ по умолчанию используется режим OAuth `legacy` со встроенным приложением VK и `client_id=6270012`.
- При переходе с VK ID на режим `legacy` установщик подставляет встроенное значение. Его можно принять клавишей Enter.

### Навык Codex

- Навык Codex автоматически подключается к задачам о VK Ads и публичных сообществах VK.
- Добавлены маршруты инструментов, готовые сценарии и формат подробного аналитического отчёта.
- Навык помогает подобрать недостающие параметры, учитывает статусы инструментов, восстанавливает авторизацию и не изменяет данные без явного запроса.
- Установщик обновляет навык вместе с MCP-сервером.

### Авторизация

- Добавлен инструмент `vk_ads_oauth_token_refresh` для ручного обновления пары токенов.
- Сброс токенов VK Ads работает, даже если текущий токен доступа уже отозван. После сброса сервер запрашивает новую пару.
- Истекающие токены VK Ads обновляются заранее. После ошибки авторизации сервер один раз обновляет токен и повторяет запрос.
- Токен VK ID также обновляется после ошибки авторизации.
- Оба инструмента управления токенами пока имеют статус `⛔️`.

### Сообщества VK

- Добавлены 10 инструментов для поиска и анализа публичных сообществ VK.
- Доступны анализ записей, оценка сообществ, фоновые исследования, локальные снимки, пересчёт и экспорт.
- Все инструменты раздела «Сообщества VK» пока имеют статус `⛔️`.
- Каталог расширен до 127 инструментов: 64 для чтения и 63 для записи. Статусы прежних 117 инструментов не изменились.

### Установка

- Приватная установка через GitHub CLI больше не показывает ошибку `curl 404` перед загрузкой релиза.

### Первая сборка

- Создан новый MCP-сервер для официального VK Ads API.
- Зарегистрировано 117 инструментов: 54 для чтения и 63 для записи.
- Из них 103 получили статус `✅`, ещё 14 — статус `⛔️`.
- Добавлены управление токенами, проверка данных перед записью, контрольное чтение и локальный журнал операций.
- Добавлены установщики для macOS, Linux и Windows, автоматическое подключение Codex и обновляемый навык.
