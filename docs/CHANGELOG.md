# История изменений

## 0.1.1 — 2026-07-30

### Поиск сообществ

- Исследование анализирует публикации и считает оценку для каждого сообщества, прошедшего первичные фильтры. Желаемое количество итоговых рекомендаций больше не ограничивает анализ.
- Стандартный порог рекомендации снижен с 60 до 45 баллов, ручной проверки — с 45 до 30.
- Навык трактует указанное пользователем количество как цель отчёта, а не как предел анализа.

## 0.1.0 — 2026-07-29

- Стабильный выпуск общего preflight для всех 64 инструментов записи и инструмента `vk_ads_action_prepare`.
- Исправлены инструкции Codex и раздел безопасности: перед записью нужно получить `ready: true`, а затем отдельный явный запрос пользователя.
- В документации исправлен счётчик: сервер содержит 129 инструментов, из которых 115 прошли живую проверку, а 14 сохранены со статусом `⛔️`.
- Сохранена совместимость с `0.0.7`, включая адресный поиск рекламных пакетов по идентификаторам.

## 0.1.0-beta.1 — 2026-07-29

### Предварительная проверка

- Добавлен инструмент только для чтения `vk_ads_action_prepare`. Он проверяет входные данные и свежее состояние кабинета, но не выполняет запись.
- Все 64 записывающих инструмента подключены к единому контракту `ActionReadiness`. Блокирующие условия, предупреждения, допустимые значения и безопасный черновик возвращаются в структурированном виде.
- Токены, адреса страниц, учётные данные, пути к файлам и персональные данные удаляются из черновика подготовки.
- Инструменты управления OAuth-токенами требуют точного текста подтверждения. Обновление токенов и полный сброс с повторной авторизацией прошли живую проверку.

### Записывающие инструменты

- Уточнены схемы и предварительные проверки кампаний, групп, объявлений, контента, аудиторий, лид-форм, опросов, подписок, прайс-листов, локальной географии, URL, приложений, профиля, ОРД и SKAdNetwork.
- Перед записью сервер читает необходимые родительские объекты и справочники. После записи выполняется поддерживаемое контрольное чтение.
- Экспорт лидов и респондентов сохраняется только в новый безопасный локальный файл.

## 0.0.7 — 2026-07-29

### Справочники

- В `vk_ads_ad_reference_list` добавлен параметр `ids`. Он позволяет адресно получить пакет вместе с `Package.options`, даже если VK не включает пакет в общий справочник.
- Навык теперь запрашивает пакет группы по его точному `packageId` и читает настройки площадок и паттернов из `options.targetings`.

## 0.6.0 — 2026-07-29

### Справочники

- Справочник пакетов теперь запрашивает дополнительное поле `options`, включая доступные `settings`, необходимые для подготовки групп и объявлений.
- Для непагинируемых справочников `packages_pads` и `pads_trees` сохранена проверенная локальная пагинация по `limit` и `offset`.

### Установка

- При обновлении установщик использует сохранённый выбор MCP-клиентов и не показывает список с галочками повторно. Для старой установки выбор восстанавливается по установленным навыкам.
- После завершения интерактивной установки процесс закрывается самостоятельно, без `Ctrl+C`.

## 0.0.5 — 2026-07-29

### Диагностика

- Ошибки VK Ads теперь содержат безопасное сообщение провайдера и пути к полям, которые не прошли проверку.
- Единая обработка применяется к обычным, файловым, пакетным и авторизационным запросам, а также к инструментам сообществ VK.
- Токены, секреты, пароли, адреса страниц, электронная почта и исходные строки файлов удаляются из диагностики.

### Установка

- Найденные MCP-клиенты показываются списком с галочками. Стрелки перемещают курсор, пробел меняет выбор, Enter подтверждает установку.
- Для продолжения должен быть выбран хотя бы один клиент. Установку без подключения к клиентам можно запустить параметром `--no-register`.
- `client_secret` запрашивается сразу после `client_id`.

## 0.0.4 — 2026-07-29

### OpenCode

- Установщик находит OpenCode и добавляет в него сервер `vk-ads`.
- Установщик сохраняет остальные параметры глобального конфига OpenCode, а перед изменением файла создаёт резервную копию.
- Навык `vk-ads-mcp` копируется в глобальный каталог навыков OpenCode и обновляется вместе с сервером.
- OpenCode можно выбрать в интерактивном режиме или явно через `--clients opencode`.

## 0.0.3 — 2026-07-29

### Установка

- Навык для работы с VK Рекламой устанавливается во все выбранные поддерживаемые клиенты, а не только в Codex.
- Для Codex CLI, Claude Code, Gemini CLI, Qwen Code, Kimi Code CLI и Cursor используются их пользовательские каталоги навыков.

### Поиск сообществ

- Поиск поддерживает явный бюджет, сортировку по числу участников или релевантности и более точные исключения.
- Фоновое исследование сразу возвращает идентификатор запуска, а поиск и анализ продолжает в фоне.
- Сохранённые результаты можно пересчитывать по новым порогам, весам, кластерам и уже проанализированным терминам без повторного запроса к VK.
- Навык помогает собрать поисковый бриф в чате или, с согласия пользователя, через отдельный интерактивный опросник.
- Исправлено чтение `auth.env` и хранение снимков исследования рядом с установленным сервером.

## 0.0.2 — 2026-07-29

### Установка

- Установщик находит Codex CLI, Claude Code, Gemini CLI, Qwen Code, Kimi Code CLI и Cursor, предлагает выбрать нужные клиенты и подключает сервер к каждому из них.
- Для автоматической установки доступны параметры `--clients`, `--all-detected` и `--no-register`.
- Перед изменением существующих конфигураций Kimi и Cursor создаются резервные копии.

## 0.0.1 — 2026-07-29

Первый ранний релиз.

### Приложение для поиска сообществ

- Для поиска сообществ по умолчанию используется режим OAuth `legacy` со встроенным приложением VK и `client_id=6270012`.
- При переходе с VK ID на режим `legacy` установщик подставляет встроенное значение. Его можно принять клавишей Enter.

### Навык Codex

- Навык Codex автоматически подключается к задачам о VK Ads и публичных сообществах VK.
- Добавлены маршруты инструментов, готовые сценарии и формат подробного аналитического отчёта.
- Навык помогает подобрать недостающие параметры, учитывает статусы инструментов, восстанавливает авторизацию и не изменяет данные без явного запроса.
- Установщик обновляет навык вместе с MCP-сервером.

### Авторизация

- Добавлен инструмент `vk_ads_oauth_token_refresh` для ручного обновления пары токенов.
- Сброс токенов VK Ads работает, даже если текущий токен доступа уже отозван. После сброса сервер запрашивает новую пару.
- Истекающие токены VK Ads обновляются заранее. После ошибки авторизации сервер один раз обновляет токен и повторяет запрос.
- Токен VK ID также обновляется после ошибки авторизации.
- Оба инструмента управления токенами пока имеют статус `⛔️`.

### Сообщества VK

- Добавлены 10 инструментов для поиска и анализа публичных сообществ VK.
- Доступны анализ записей, оценка сообществ, фоновые исследования, локальные снимки, пересчёт и экспорт.
- Все 10 инструментов сообществ прошли проверку реальными вызовами.
- Каталог расширен до 128 инструментов: 64 для чтения и 64 для записи. Проверку прошли 112 инструментов, ещё 16 пока недоступны или не проверены.

### Установка

- Для Windows, macOS и Linux используется одна команда `npx`.
- Единственный установочный файл — `install.mjs`.

### Первая сборка

- Создан новый MCP-сервер для официального VK Ads API.
- Зарегистрировано 117 инструментов: 54 для чтения и 63 для записи.
- Из них 103 получили статус `✅`, ещё 14 — статус `⛔️`.
- Добавлены управление токенами, проверка данных перед записью, контрольное чтение и локальный журнал операций.
- Добавлены универсальный установщик, автоматическое подключение Codex и обновляемый навык.
