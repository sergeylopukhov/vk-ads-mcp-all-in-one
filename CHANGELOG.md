# История изменений

Все заметные изменения фиксируются в этом файле.

## 0.2.0 — 2026-07-29

- Перенесены 10 read-only инструментов поиска и анализа публичных сообществ VK.
- Добавлены отдельный Core VK API client, VK ID token refresh, кеш metadata, ограничение запросов, анализ записей, скоринг, фоновые исследования, локальные TTL-снимки, пересчёт и экспорт.
- Все инструменты раздела «Сообщества VK» отмечены `⛔️`; live-проверка не выполнялась.
- Каталог расширен до 127 tools: 64 read и 63 write; live-статусы прежних 117 tools не изменены.

## 0.1.1 — 2026-07-29

- Приватная установка через GitHub CLI больше не показывает ожидаемый `curl 404` перед безопасным переходом к release download.
- GitHub Actions обновлены до актуального runtime.

## 0.1.0 — 2026-07-29

- Создан новый MCP-сервер для официального VK Ads API.
- Зарегистрировано 117 инструментов: 54 read и 63 write.
- Полный успешный live-тест прошли 103 точных MCP tools; 14 инструментов оставлены с честным статусом `⛔️`.
- Добавлены управление токенами, preflight операций записи, контрольное чтение и санитизированный аудит.
- Добавлены установщики для macOS, Linux и Windows, автоматическое подключение Codex и обновляемый навык.
- Подготовлена публичная документация и перенесены визуальные материалы предыдущего проекта автора.
